# SomApp-website (KNN MicroPay)

A modern web application and micro-wallet backend integrated with Firebase Firestore and the Polygon blockchain network.

## Features
- **Polygon Wallet Generation:** Automatically generates secure blockchain deposit addresses for users using `ethers.js`.
- **Firebase Backend Integration:** Stores user balances, emails, and wallet data securely in Firestore.
- **Polymarket Style UI:** Clean, responsive, and modern mobile-first interface designed with Tailwind CSS and Lucide icons.

## Tech Stack
- **Backend:** Node.js, Express, Firebase Admin SDK, Ethers.js, CORS
- **Frontend:** HTML5, Tailwind CSS, JavaScript
- **Hosting & Deployment:** Railway
